Опис функції

Функція `eta\_hours(distance\_km, express)` обчислює час доставки в годинах:

\- Звичайна доставка: 24 години базово + 1 година за кожні повні 100 км.

\- Експрес-доставка (`express=True`): підсумковий час ділиться навпіл, але не менше 4 годин.

\- При від'ємній відстані (`distance\_km < 0`) викликається помилка `ValueError`.
